# 旧チャンネルの記録(2026年11月まで)

YouTubeチャンネルを別のGoogleアカウントで作り直したため、旧チャンネルの記録をここに移した。
新しいチャンネルは、リポジトリ直下の空の記録から始める。

| ファイル | 内容 |
|---|---|
| `upload_history.json` | 旧チャンネルにアップロードしたShorts(516件)。単語・モード・video_idなど |
| `repost_state.json` | 旧チャンネルで通常動画に変換済み・スキップ済みのvideo_id |
| `comment_request_state.json` | 旧チャンネルで処理済みのコメントID |
| `quota_usage.json` | 旧チャンネル最終日のAPIクォータ消費 |
| `video_ids.txt` | 旧チャンネルの動画IDの一覧(手動メモ。コードからは参照していない) |

コードからは参照しない(参照すると、新しいチャンネルで旧動画を変換・集計しようとしてしまう)。
旧チャンネルの動画を新しいチャンネルへまとめて上げ直すことはしない
(再利用されたコンテンツと判定されやすいため)。モード別の実績(どのモードが伸びたか)は
README の「ハマった罠」に記録済みで、config.MODE_WEIGHTS に反映されている。
